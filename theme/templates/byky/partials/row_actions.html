{% comment %} Shared row-actions kebab menu (Edit + Delete) for .scr-* list tables -- the "More" menu first built on Country & State Management. No JS to wire per screen: byky-screen.js already handles [data-scr-menu-toggle] (open/close) and [data-scr-delete] (SweetAlert2 confirm, falls back to a native confirm). Usage -- inside a , wrap it in the row's own .scr-row-actions div so it can sit next to a screen-specific icon button (e.g. Approve):
{% include "byky/partials/row_actions.html" with edit_open="branch:edit" %}
`edit_open` must match the drawer's data-scr-open key (its scr_name:edit). A screen that edits on its own page (Fares) passes `edit_href` instead: the item becomes a link, reading "View" for someone who may not update. Edit and Delete are hidden unless the screen's `perm` dict allows them; the server refuses the action either way -- hiding a control is a courtesy, the refusal is the control. Frontend-only, per CLAUDE.md 1: Delete has no backend write behind it. {% endcomment %}
